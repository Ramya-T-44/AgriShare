# 🌾 AgriShare – Farmers Agricultural Equipment Rental & Sharing Platform

AgriShare is a web-based agricultural equipment rental and sharing platform designed to help farmers access farming equipment at affordable rental prices.

The platform connects farmers who own agricultural equipment with farmers who need it. Instead of purchasing expensive machinery, farmers can find and request equipment from other farmers, helping reduce farming costs and improve equipment utilization.

## 🎯 Project Objective

The main objective of AgriShare is to provide an affordable and accessible way for farmers to share agricultural equipment within their local communities.

It aims to:
- Reduce the financial burden of purchasing expensive agricultural machinery.
- Connect equipment owners with farmers who need machinery.
- Encourage resource sharing among farmers.
- Improve the utilization of available agricultural equipment.
- Support small and medium-scale farmers.

## 🚜 Key Features

- **Farmer Registration & Login:** Farmers can create accounts and securely access the platform.
- **Equipment Listing:** Equipment owners can add their agricultural machinery with details.
- **Equipment Search:** Farmers can browse and search for available equipment.
- **Rental Requests:** Farmers can send requests to equipment owners.
- **Availability Management:** Owners can manage the availability of their equipment.
- **Farmer Dashboard:** Users can manage their equipment listings and rental requests.
- **Equipment Details:** View equipment name, type, description, rental price, and availability.

## 🛠️ Technologies Used

| Technology | Purpose |

| CSS3 | Styling and responsive design |
| JavaScript | Frontend interactivity |
| Python | Backend programming |
| Flask | Web application framework |
| MySQL | Database management |

## 🏗️ System Architecture

The application follows a three-layer architecture:

1. **Presentation Layer:** HTML, CSS, and JavaScript provide the user interface.
2. **Application Layer:** Python Flask handles user requests, authentication, and rental operations.
3. **Database Layer:** MySQL stores farmer details, equipment information, and rental requests.

## 👥 Target Users

- Small-scale farmers
- Medium-scale farmers
- Agricultural equipment owners
- Farmers looking for affordable machinery

## 🌱 Social Impact

AgriShare aims to promote sustainable agriculture by encouraging farmers to share existing agricultural resources.

The platform can help:
- Reduce unnecessary machinery purchases.
- Make agricultural equipment more accessible.
- Encourage cooperation among local farmers.
- Support cost-effective farming practices.
